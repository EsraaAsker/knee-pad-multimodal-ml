# Reviewer-Response Evidence and Provenance

This file records the **verified, manuscript-relevant evidence** retained for the revision. It is intended to make the distinction between experimental families explicit and to prevent unsupported historical claims from being presented as reproducible final results.

## 1. Verified CNN--Transformer development result

Source: `results/summaries/baseline_B_ensemble_summary.csv`.

- Accuracy: **85.58 ± 3.56%**
- Balanced Accuracy: **86.06 ± 3.02%**
- Macro-F1: **85.85 ± 3.26%**

This is the verified Baseline-B multimodal CNN--Transformer development result. The unsupported alternative claim of **85.58 ± 4.16% from 15 seeds with p=1.000 is not retained**.

## 2. Strict participant-independent squat result

Source: `results/summaries/strict_subject_heldout_summary.csv`.

- Segment-level Accuracy: **62.03 ± 7.11%**
- Segment-level Balanced Accuracy: **62.55 ± 6.97%**
- Segment-level Macro-F1: **61.37 ± 7.21%**

Protocol: participant-grouped outer evaluation with grouped inner validation, train-only normalization, and no participant overlap between training and test partitions.

These results belong to the strict participant-independent evaluation family and should not be described as a re-run or direct replacement of the archived 85.58% development result.

## 3. Archived conventional benchmark

The manuscript's archived benchmark includes the engineered-feature ExtraTrees reference for squat execution-quality assessment (**89.43 ± 2.60% BA**) and the broader binary execution-quality result (**68.82 ± 3.71% BA for eight IMUs; 64.73 ± 5.46% for the archived one-IMU configuration**).

These archived results are retained as historical benchmark/provenance results. Their exact original fold-generation implementation is not fully preserved in the current machine-readable package, so they should not be presented as if they were generated by the strict participant-independent pipeline.

## 4. Gait numbers are from different tasks

The apparently conflicting gait values are not from the same experiment:

- **92.67% / 94.29%**: Gait-only binary Correct-versus-Wrong evaluation, reporting recalls for the two gait error categories.
- **30.95% / 44.44%**: joint nine-class Level-3 classification, reporting recalls for Gait_NF and Gait_HA.

They therefore must be described as results from different task definitions/protocols and should not be directly compared.

## 5. Sensor configuration provenance

The historical `f1`/one-IMU label denotes a **one-IMU configuration**. The physical anatomical identity of the archived `f1` configuration is not treated as verified provenance.

The historical reduced-sensor sweep that used held-out test performance for model-selection/epoch selection is **quarantined from final leakage-safe claims**. The repository should not imply that those reduced-sensor comparisons are equivalent in evidentiary status to the strict full-sensor result.

## 6. Dataset availability

The KneE-PAD dataset is publicly available from its original publication. The dataset itself is **not redistributed** in this repository. The repository provides source code, configuration information, and selected machine-readable result summaries/diagnostics.

## 7. Reproducibility scope

The repository is intended to answer the code/data-availability request by providing:

- preprocessing scripts;
- training scripts;
- evaluation and aggregation scripts;
- experiment settings;
- verified result summaries;
- diagnostic outputs;
- a clear separation between archived and strict experimental families.

No raw patient data, model checkpoints, or unsupported historical artifacts are included.

## 8. Claims deliberately not retained as verified final evidence

The following are not treated as verified final results:

- 15-seed **85.58 ± 4.16%** result;
- associated **p=1.000** claim for that 15-seed result;
- anatomical interpretation of archived `f1` unless independently documented;
- leakage-sensitive historical sensor-reduction comparisons as final participant-independent evidence.
